# Analytics SQL Project

## Описание проекта
Анализ данных розничных продаж с использованием SQL. Проект демонстрирует навыки работы с реляционными базами данных, оконными функциями и аналитическими запросами.

---

## Структура базы данных

| Таблица | Описание |
|---------|----------|
| **customers** | клиенты (пол, возраст) |
| **products** | товары (категория, цена) |
| **malls** | торговые центры |
| **payment_methods** | способы оплаты |
| **transactions** | транзакции (500 записей) |

## Ключевые навыки

| Навык | Описание |
|-------|----------|
| Создание таблиц с FOREIGN KEY | Установлены связи между 5 таблицами |
| Генерация тестовых данных | Создано 500 транзакций через хранимую процедуру |
| JOIN (INNER, LEFT) | Объединение таблиц в аналитических запросах |
| Агрегатные функции | SUM, COUNT, AVG для вычисления метрик |
| Оконные функции | ROW_NUMBER для ранжирования клиентов и товаров |
| CASE выражения | Группировка по возрастам и уровням активности |

## Ключевые выводы

### 📊 Клиентская аналитика
- **Топ-1 клиент** (ID 5) принес 450,000 руб. (15% от общей выручки)
- **Женщины 25-34 лет** — самая активная возрастная группа
- **30% клиентов** имеют "Высокую активность" (>15 покупок)

### 🏷️ Товарная аналитика
- Категория **"Electronics"** лидирует с 150 проданными единицами
- Средний чек в категории **"Electronics"** — 35,000 руб.
- **"Clothing"** — самая частотная категория (60 чеков)

### 🏢 Географическая аналитика
- ТЦ **"Mega"** — лидер по выручке (1,250,000 руб.)
- ТЦ **"Viva Land"** показывает стабильный рост продаж

### 💳 Способы оплаты
- **Credit Card** — основной способ (40% транзакций)
- **Mobile Payment** набирает популярность (24% транзакций)

Как запустить
1. Требования
MySQL 8.0 или выше

MySQL Workbench / DBeaver (опционально)

2. Создайте базу данных
sql
CREATE DATABASE retail_db;
USE retail_db;
3. Создайте таблицы
Выполните скрипт database/schema.sql:

sql
SOURCE database/schema.sql;
4. Заполните данными
Выполните скрипт database/data.sql (сгенерирует 500 транзакций):

sql
SOURCE database/data.sql;
5. Запустите аналитические запросы
Выполните файл из папки queries/:

sql
SOURCE queries/queries.sql;
Альтернативный способ
Откройте файлы в MySQL Workbench и выполните их по очереди.
